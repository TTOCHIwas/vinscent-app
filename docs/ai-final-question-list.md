# 확정 질문 목록

## 기초 질문

### 개인 성향과 가치관

1. 요즘 네가 가장 소중하게 지키고 싶은 건 뭐야?
2. 힘든 선택을 할 때 가장 중요하게 생각하는 기준은 뭐야?
3. 아무 일정도 없는 하루가 생기면 어떻게 보내고 싶어?
4. 요즘 예전과 달라졌다고 느끼는 생각이나 가치가 있어?

### 애정 표현과 정서적 지원

1. 기분이 가라앉았을 때 상대가 어떻게 곁에 있어주면 가장 힘이 돼?
2. 상대에게 사랑받고 있다고 가장 크게 느끼는 순간은 언제야?
3. 고마운 마음을 표현할 때 가장 자연스러운 방법은 뭐야?
4. 요즘 상대에게 받고 싶은 작은 배려가 있다면?

### 대화와 갈등 회복

1. 생각이 다를 때 어떤 대화를 하면 이해받았다고 느껴?
2. 다툰 뒤 마음을 다시 열게 되는 상대의 행동은 뭐야?
3. 서운할 때 바로 말하는 편이야, 생각을 정리할 시간이 필요한 편이야?
4. 우리 대화에서 앞으로도 지키고 싶은 좋은 방식은 뭐야?

### 일상 취향과 함께하는 활동

1. 함께 있을 때 가장 편안한 일상의 모습은 어떤 장면이야?
2. 혼자만의 시간이 필요할 때 상대가 어떻게 알아주면 좋겠어?
3. 둘이 함께 정하면 좋겠다고 느끼는 생활 습관이 있어?
4. 최근 함께 해보고 싶은 소소한 활동은 뭐야?

### 관계의 기억과 강점

1. 우리 사이가 단단하다고 느꼈던 순간은 언제야?
2. 상대의 어떤 모습 때문에 처음 마음이 갔어?
3. 함께 겪어서 더 가까워졌다고 느낀 일이 있어?
4. 우리 관계에서 앞으로도 잃고 싶지 않은 장점은 뭐야?

### 미래 기대와 관계의 경계

1. 앞으로 1년 동안 둘이 함께 이루고 싶은 작은 목표는 뭐야?
2. 서로의 선택을 존중하기 위해 꼭 지키고 싶은 선은 뭐야?
3. 바쁜 시기에도 우리 관계를 위해 남겨두고 싶은 시간은 언제야?
4. 우리의 미래를 생각할 때 가장 기대되는 장면은 뭐야?

6. 언젠가 함께 살아보고 싶은 동물이나 키워보고 싶은 식물이 있어?

### 둘의 시작

1. 처음 만났을 때 상대가 어떤 사람일 거라고 생각했어?
2. 첫인상과 지금 모습 사이에서 가장 달라 보이는 점은 뭐야?
3. 처음 둘이 오래 이야기했던 날에 무슨 얘기를 했는지 기억나?
4. 첫 데이트나 처음 둘이 따로 보낸 날에서 가장 기억나는 장면은 뭐야?
5. 처음 주고받던 연락의 분위기는 어땠어?
6. 서로 농담할 만큼 편해졌다고 처음 느낀 순간은 언제였어?

## 관계 회고와 표현

### 개인적인 보물과 나만의 세계

1. 어릴 때 보물처럼 아끼던 물건은 뭐였어?
2. 남들은 평범하게 봐도 너에게 특별한 물건이 있어?
3. 혼자만 알고 싶을 만큼 아끼는 장소는 어떤 곳이야?
4. 어릴 때 받은 선물 중 지금도 가장 생생하게 기억나는 건 뭐였어?
5. 버리지 못하고 남겨둔 오래된 물건이 있다면, 어떤 사연 때문에 지금까지 남겨뒀어?
6. 어린 시절의 너에게서 지금 하나 가져올 수 있다면 뭘 가져오고 싶어?

### 처음의 호감과 관계 속 변화

1. 처음 만난 날, 상대의 목소리나 말투는 어떻게 기억나?
2. 상대가 생각보다 재미있는 사람이라고 처음 느낀 순간은 언제야?
3. 연애 초반 상대가 유난히 좋아했던 건 뭐였어?
4. 처음 상대에게 잘 보이고 싶어서 무엇을 가장 신경 썼어?
5. 만나면서 상대에게 새로 생긴 좋은 습관이 있어?
6. 처음에는 몰랐지만 만나면서 점점 좋아진 상대의 모습은 뭐야?

### 둘의 추억을 새롭게 꺼내기

1. 둘이 함께한 날 중 제목을 붙여보고 싶은 하루는 언제야?
2. 둘이 함께한 순간을 떠올릴 때 같이 생각나는 소리나 냄새는 뭐야?
3. 둘의 추억 하나에 영화 제목처럼 이름을 붙여봐.
4. 둘의 추억 하나를 세 개의 이모티콘으로 표현해봐.
5. 둘이 처음 함께 해본 일 하나를 다시 한다면, 무엇을 다르게 해보고 싶어?

### 상대의 관점으로 보기

1. 상대가 자주 쓰는 말투를 다정하게 흉내 내서 오늘 하루를 정리해봐.
2. 상대가 너를 다정하게 소개한다고 상상하고 한 문장으로 적어봐.
3. 상대가 고를 것 같은 네 장점 세 가지를 적어봐.
4. 상대가 너를 만화 캐릭터로 그린다고 상상하고, 어떤 표정일지 적어봐.
5. 상대가 지금 보낼 것 같은 이모티콘 하나와 그 이유를 적어봐.
6. 서로 역할이 바뀐 하루를 상상하고 가장 먼저 할 일을 적어봐.

### 상대에게 바라는 작은 돌봄

1. 상대가 계속 해줬으면 하는 행동 하나와 그 이유를 적어봐.
2. 요즘 상대가 먼저 어떤 걸 물어봐주면 좋겠어?
3. 상대에게 작은 부탁 하나를 한다면 무엇을 부탁하고 싶어?
4. 특별한 날이 아니어도 상대가 무엇을 챙겨주면 기분이 좋아질까?
5. 상대가 먼저 "같이 하자"고 말해주면 가장 반가울 일은 뭘까?
6. 요즘 네가 애쓰는 일 중 상대가 알아줬으면 하는 건 뭐야?

### 하지 않았으면 하는 것과 경계

1. 장난으로도 편하게 넘기기 어려운 말이나 행동은 어떤 거야?
2. 다른 사람 앞에서 상대가 지켜줬으면 하는 선이 있어?
3. 둘의 사진이나 이야기를 다른 사람에게 전할 때, 어떤 내용은 꼭 먼저 물어봐줬으면 해?
4. 약속이 바뀔 때 상대가 어떻게 알려줬으면 해?
5. 감정이 격해졌을 때 어떤 식의 대화가 가장 힘들어?
6. 상대가 하지 않았으면 하는 행동 하나를, 대신 바라는 행동과 함께 적어봐.

### 둘만의 약속과 작은 활동

1. 서로에게 꼭 지켜주고 싶은 약속을 한 문장으로 적어봐.
2. 둘이 다툴 때 잠깐 멈추자는 신호를 하나 정해봐.
3. 바쁜 날에도 유지하고 싶은 최소한의 연락 방식을 적어봐.
4. 혼자 쉬고 싶다는 뜻을 편하게 전할 문장을 만들어봐.
5. 둘이 한 달에 한 번 같이 하고 싶은 작은 일을 하나 정해봐.
6. 서로 잘한 일을 발견했을 때 표현할 둘만의 방식을 정해봐.

### 상대에게 들려주고 싶은 과거

1. 상대가 아직 모를 것 같은 어린 시절의 네 모습은 뭐야?
2. 상대에게 들려주고 싶은 학창 시절 이야기가 있어?
3. 상대에게 예전에 즐기던 취미나 놀이 하나를 소개한다면 뭘 고를래?
4. 네 과거의 한 장면을 상대가 직접 볼 수 있다면 어떤 날을 고를래?
5. 옛 친구가 지금의 너를 보면 가장 놀랄 변화는 뭐야?
6. 어릴 때의 네가 지금 상대를 만났다고 상상하고, 처음 건넬 말을 적어봐.
