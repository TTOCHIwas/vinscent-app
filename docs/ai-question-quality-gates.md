# AI 질문 품질 게이트

## 목적

개인화 질문은 모델 출력만 신뢰하지 않는다. 생성 시점의 문맥, 결정적
한국어 품질 검사, 최근 노출 주제 검사, 후보 신선도 검사를 순서대로
통과한 질문만 사용자에게 노출한다.

## 한국어 자연스러움

`im-not-ai`의 전체 윤문 파이프라인을 런타임 의존성으로 사용하지 않는다.
단짠의 출력은 짧은 질문 한 문장이므로 장문 리듬과 문단 밀도 규칙을
적용하면 오탐이 커지고, 별도 윤문 호출은 질문의 의미를 바꿀 수 있다.

다음 원칙만 단짠의 결정적 검사에 맞게 적용한다.

- 의미 보존: 생성된 질문을 자동으로 고쳐 쓰지 않고 거부 후 재생성한다.
- 국소 탐지: 문제가 확인된 문자열 구간과 출처 규칙을 함께 반환한다.
- 과잉 수정 방지: 짧은 구어에서 한 번만 나와도 부자연스러운 표현만 막는다.
- 톤 유지: 반말 질문 계약과 기존 문자·안전 정책을 그대로 사용한다.

현재 적용한 참조 규칙은 다음과 같다.

| 참조 | 단짠에서 차단하는 표현 |
|---|---|
| `A-3` | `~에 있어서` |
| `A-5` | `~와 관련하여`, `~과 관련해서` |
| `A-6` | `~에 기반하여`, `~을 바탕으로` |
| `A-8` | `~되어진` |
| `A-9` | `~에 의해` |

목적어와 동사가 맞지 않는 `해보고 싶은 영화`, `보고 싶은 활동` 같은
조합은 단짠 전용 규칙으로 검사한다.

다음 규칙은 의도적으로 적용하지 않는다.

- `~에 대해`, `가지고 있다`: 단발성 구어에서는 자연스러울 수 있다.
- 이항 선택 질문: 커플 질문에서 필요한 형식이다.
- 문장 길이, 문단 리듬, 불릿, 헤딩, 종결 반복: 장문용 밀도 규칙이다.
- 자동 윤문과 변경률 게이트: 질문 의미와 구조화 출력 계약을 훼손할 수 있다.

## 반복 질문

반복 검사는 서로 다른 목적의 신호를 섞지 않는다.

- `near_duplicate`: 같은 정보를 표현만 바꿔 다시 묻는 질문
- `topic_overlap`: 같은 주제를 다른 관점에서 묻는 질문
- `distinct`: 질문 문장 틀이 비슷해도 주제가 다른 질문

최근 노출과 대기 후보는 모델에 금지 목록으로만 전달한다. 질문 근거나
이어갈 단서로 사용하지 않는다. 후보 생성 뒤 더 새로운 질문이 생기면
해당 자동 후보는 할당 전에 만료한다.

## 의미 유사도 평가

Cloudflare BGE-M3 평가는 운영 경로와 분리한다. 정적 한국어 사례만
사용하며 원문 점수와 의미 초점 점수를 함께 측정한다.

의미 초점은 `둘이`, `함께`, `같이`, `싶은`, 질문형 끝맺음처럼 여러
주제에서 반복되는 틀을 제거하고 핵심 주제어만 남긴다. 원문과 의미 초점
중 어느 쪽이 오탐을 줄이는지는 평가 결과로 판단한다.

보고서는 두 종류의 임계값을 제공한다.

- `f1Optimal`: 정밀도와 재현율의 조화 평균이 가장 높은 탐색 결과
- `precisionFirst`: 정밀도 0.95 이상을 먼저 만족한 뒤 재현율이 가장 높은 결과
- `topicCooldownValidation.hybridPrecisionFirst`: 기존 어휘 검사, 원문 점수,
  의미 초점 점수 중 하나라도 고신뢰 조건을 만족하는 결합 결과
- `topicCooldownValidation.leaveOneScenarioOut`: 한 주제 시나리오 전체를
  임계값 탐색에서 제외한 뒤 해당 시나리오를 평가한 결과

결합 평가는 원문과 의미 초점 채널을 모든 폴드에서 유지한다. 학습 표본에서
한 채널이 추가 이득을 만들지 못하면 해당 채널의 임계값을 학습 최대값보다
높게 두며, 채널 자체를 `null`로 제거하지 않는다.

이 값들은 자동으로 운영 코드에 반영하지 않는다. 평가 사례의 수가 적거나
오탐이 남아 있으면 기존 결정적 검사와 후보 신선도 보장만 사용한다.

### 2026-08-26 평가

BGE-M3 한국어 40쌍의 `v2` 점수를 새 평가기로 다시 분석했다.

| 입력 방식 | 평가 구간 | 정밀도 | 재현율 | F1 |
|---|---|---:|---:|---:|
| 원문 | 전체 표본 | 1.00 | 0.55 | 0.710 |
| 의미 초점 | 전체 표본 | 1.00 | 0.70 | 0.824 |
| 결합 | 전체 표본 | 1.00 | 0.75 | 0.857 |
| 원문 | 시나리오 홀드아웃 | 1.00 | 0.50 | 0.667 |
| 의미 초점 | 시나리오 홀드아웃 | 1.00 | 0.65 | 0.788 |
| 결합 | 시나리오 홀드아웃 | 1.00 | 0.65 | 0.788 |

전체 표본에서 결합 방식은 원문 임계값 `0.8134765625`, 의미 초점 임계값
`0.61767578125`로 20개의 반복 주제 중 15개를 찾고 다른 주제 20개는
차단하지 않았다. 그러나 시나리오 홀드아웃에서는 13개만 찾아 의미 초점
단독보다 개선되지 않았다.

현재 의미 초점은 공통 문장 틀로 인한 오탐을 줄이지만 `영화`와 `작품`,
`목표`와 `버킷리스트`처럼 핵심 표현이 달라지는 질문을 놓친다. 따라서 이
결과는 결합 게이트의 운영 활성화 근거가 아니다. 독립적인 실제 회귀 사례를
추가하고 시나리오 홀드아웃에서 결합 방식의 개선과 임계값 안정성을 다시
확인한 뒤, 호출 비용과 지연 시간을 포함해 별도로 승인한다.
