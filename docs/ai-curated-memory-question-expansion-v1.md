# 기억 확장 질문 초안 v1

작성일: 2026-09-01

## 목적

확정된 일반 질문 96개와 별도로, 개인의 과거와 둘의 시작에 관한 가볍고
구체적인 기억을 나눌 수 있는 질문을 보강한다.

이 질문들은 기존 여섯 학습 영역의 균형과 진행도를 대체하지 않는다. 48개
모두 사용자 검토를 마쳤으며, 확정된 일반 질문은 총 144개가 된다.

## 구성 원칙

- 8개 기억 주제마다 6개씩, 전체 48개를 구성한다.
- 이항 선택과 빈칸 채우기 형식은 사용하지 않는다.
- 이름, 학교명, 주소처럼 개인을 식별할 수 있는 답을 요구하지 않는다.
- 반려동물이나 식물을 키웠다는 사실은 단정하지 않고 조건부로 묻는다.
- 좋은 기억만 있었다고 가정하지 않으며 상실, 가족 갈등, 괴롭힘처럼 답변이
  갑자기 무거워질 수 있는 주제는 이번 범위에서 제외한다.
- 한 질문에는 한 가지 기억만 묻는다.
- 운영 노출 비율과 기존 학습 영역 매핑은 질문 검토가 끝난 뒤 결정한다.
