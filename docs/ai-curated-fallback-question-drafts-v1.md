# 일반 질문 폴백 초안 v1

작성일: 2026-08-28

## 목적

AI 개인화 질문을 만들 수 없을 때에도 이미 노출된 질문을 다시 사용하지 않고
안정적으로 배정할 수 있도록 일반 질문 후보를 검토한다.

이 문서는 최종 운영 데이터가 아니라 검토용 초안이다. 기존 기초 질문 24개와
분리된 새 질문 144개를 담고 있으며, 사용자 검토와 품질 평가를 거쳐 이 중
96개를 1차 운영 풀로 선정하는 것을 목표로 한다.

## 구성

- 학습 영역: 6개
- 질문 관점: 영역마다 `preference`, `lived_experience`, `scenario`,
  `current_need` 4개
- 관점별 초안: 6개
- 영역별 초안: 24개
- 전체 초안: 144개
- 깊이: `light`, `exploratory`, `deep`

검토할 때는 질문 ID와 함께 `채택`, `수정`, `제외` 중 하나를 남긴다.

## 작성 기준

- 기존 기초 질문 24개와 같은 정보를 표현만 바꿔 다시 묻지 않는다.
- 실제로 일어났는지 모르는 사건은 단정하지 않는다.
- 가정 질문은 `~라면`, `~한다면`, `~생긴다면`처럼 가정임을 드러낸다.
- `오늘`, `내일`, `이번 주말`, `다음 주말`, `지난달`처럼 배정 시점에 따라
  의미가 달라지는 표현을 쓰지 않는다.
- 두 사람이 각각 답할 수 있는 한 가지 질문만 담는다.
- 진단, 관계 평가, 성적 내용, 재정, 건강, 종교, 정치, 가족 갈등을 묻지 않는다.
- 반말 한 문장으로 쓰고 물음표로 끝낸다.
- 특정 답을 유도하거나 상대의 행동을 사실로 가정하지 않는다.
