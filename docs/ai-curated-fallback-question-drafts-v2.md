# 일반 질문 폴백 초안 v2

작성일: 2026-08-28

## 목적

AI 개인화 질문을 만들 수 없을 때 이미 노출된 질문을 반복하지 않으면서,
사용자가 부담 없이 답하고 개인화에 필요한 데이터를 남길 수 있는 일반 질문
풀을 구성한다.

v2는 학습 영역의 균형을 유지하되, 질문을 심리 검사나 관계 점검처럼 느끼게
했던 v1의 답변 부담을 낮춘 초안이다.

## 구성

- 학습 영역: 6개
- 영역별 질문: 24개
- 전체 질문: 144개
- 영역별 질문 각도: `preference` 10개, `lived_experience` 6개,
  `scenario` 4개, `current_need` 4개
- 전체 답변 부담: `light` 109개, `medium` 35개

학습 영역과 질문 각도는 균형을 유지하지만 난이도는 영역마다 억지로
균등화하지 않는다. 일반 폴백의 역할에 맞춰 `deep` 질문은 두지 않는다.

## 작성 기준

- 여섯 학습 영역을 각각 24개로 동일하게 구성한다.
- 대부분의 질문은 5~15초 안에 답할 수 있게 한다.
- 추상적인 가치 판단보다 음식, 연락, 일정, 사진, 취미처럼 구체적인 장면을
  사용한다.
- 실제로 일어났는지 모르는 사건은 `있어?`, `떠오르는 게 있어?`로 묻는다.
- 상황 질문은 `~라면`, `~한다면`으로 가정임을 분명히 한다.
- 갈등, 결핍, 관계 평가를 전제하지 않는다.
- 두 사용자가 각각 답할 수 있는 한 가지 질문만 담는다.
- 배정 날짜에 따라 의미가 달라지는 표현과 차단 주제를 사용하지 않는다.

검토 의견은 질문 ID와 함께 `채택`, `수정`, `제외` 중 하나로 기록한다.
