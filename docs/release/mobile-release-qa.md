# 모바일 출시 후보 QA

이 체크리스트는 자동 테스트가 대신할 수 없는 실제 Android·iOS 권한,
카메라, 녹음, 알림, 위젯, 두 사용자 실시간 동기화를 검증한다. 출시
후보와 동일한 backend 환경 및 서명 build를 사용한다.

## 2. 설치와 인증

- [ ] Android fresh install 후 검은 화면이나 무한 로딩 없이 로그인 화면 표시
- [ ] iOS fresh install 후 검은 화면이나 무한 로딩 없이 로그인 화면 표시
- [ ] 카카오 로그인 성공·취소·실패 후 정상 화면 유지
- [ ] Apple 로그인 성공·취소·실패 후 정상 화면 유지
- [ ] 앱 강제 종료 후 인증 세션 복원
- [ ] 로그아웃 후 push token과 로컬 사용자 데이터 정리
- [ ] 네트워크 단절 상태 시작 후 복구·재시도 가능

## 3. 온보딩과 커플 연결

- [ ] 닉네임·생일 입력과 validation
- [ ] 초대 코드 생성·복사·입력
- [ ] 한 사용자만 코드를 입력해 두 계정 연결
- [ ] 설정 담당자는 만난 날과 캐릭터 단계 진행
- [ ] 상대 계정에는 설정 중 대기 상태 표시
- [ ] 캐릭터 건너뛰기 후 기본 캐릭터와 그리기 안내 표시
- [ ] 만난 날 당일을 1일로 계산
- [ ] 이미 사용됐거나 잘못된 코드의 오류 처리

## 4. 홈과 실시간 동기화

- [ ] A가 올린 카드가 B 홈에 앱 재실행 없이 표시
- [ ] B가 올린 카드가 A 홈에 앱 재실행 없이 표시
- [ ] 두 카드가 고정된 본인·상대 위치에 표시
- [ ] 질문 생성이 양쪽 홈에 실시간 반영
- [ ] 답변 완료와 AI 한마디가 재진입 없이 반영
- [ ] 카드·질문을 눌렀을 때 요구된 상세·수정·답변 경로로 이동
- [ ] 선제 추천 말풍선 유지와 옆으로 넘겨 닫기
- [ ] 녹음 슬롯 그림 이동이 상대 화면에 실시간 반영
- [ ] 겹친 홈 요소는 위에 있는 요소가 먼저 선택됨

## 5. 카드와 질문

- [ ] 후면·전면 카메라 전환
- [ ] 카메라 확대·축소와 촬영
- [ ] 사진 위 텍스트·그림·짧은 글 작성
- [ ] 그리기 undo·redo·지우개·펜 굵기
- [ ] 저장 중 중복 탭과 네트워크 실패 처리
- [ ] 질문 생성 전 본인 카드 수정 가능
- [ ] 질문 생성 후 본인·상대 카드 모두 상세 보기만 가능
- [ ] 두 답변 완료 후 답변 수정 불가
- [ ] 카드 상세 다운로드 후 갤러리의 이미지 품질 확인
- [ ] 긴 질문·답변이 단어 단위로 줄바꿈되고 잘리지 않음

## 6. 녹음과 보관함

- [ ] 캐릭터 길게 누르기로 녹음 시작·종료
- [ ] 녹음 준비·진행·재생 indicator가 캐릭터 아래에 표시
- [ ] 재생 중 캐릭터 bounce가 매번 동작
- [ ] 보관함 슬롯 생성, 제목·그림 저장
- [ ] 항목 선택 재생과 더보기 하단 시트
- [ ] 슬롯 그림 길게 눌러 홈 중앙 초기 위치에 배치
- [ ] 슬롯 교체와 휴지통 drag 제거
- [ ] 녹음 저장 후 상대방 push 수신
- [ ] 앱 종료·백그라운드 전환 중 녹음 draft 복구

## 7. 캘린더와 일정

- [ ] 최초 진입 시 오늘 선택
- [ ] 월간·전체·주간 상태가 한 gesture에 한 단계만 전환
- [ ] 월·주·일 좌우 이동 애니메이션과 swipe 임계값
- [ ] 캘린더 전체 상태에서 floating dock이 셀을 가리지 않음
- [ ] 휴대전화와 태블릿에서 날짜·요일·셀 요소가 겹치지 않음
- [ ] 카드 0·1·2장과 일정 그림 0·1·2·3장 이상 조합 확인
- [ ] 셀 미리보기의 모두·카드만·일정만 개인 설정 유지
- [ ] 일정 기본 정보와 선택적 그림·메모 저장
- [ ] 반복 안 함·매년 반복과 기본 기념일 계산
- [ ] 일정 알림 날짜·시간과 토글 적용
- [ ] 두 사용자 모두 공유 일정 수정·삭제
- [ ] 일정 상세 하단 시트가 floating dock보다 위에 표시
- [ ] 콘텐츠가 화면을 넘지 않으면 불필요한 scroll이 없음

## 8. AI

- [ ] AI 동의 전 안내와 AI 탭 이동
- [ ] 24개 기초 질문 순서·진행·두 사용자 답변
- [ ] 24개 완료 전 카드에는 질문을 붙이지 않음
- [ ] 기억 후보가 맞아·아니야로 검토되고 화면이 번쩍이지 않음
- [ ] 양쪽 승인 전 공유 개인화가 활성화되지 않음
- [ ] 한 줄 피드백에 작은 AI 생성 표시와 신고 진입점 존재
- [ ] 직접 질문 제출 후 준비·완료 상태 갱신
- [ ] 정보 부족 답변에서 원 질문과 가까운 공유 질문 후보 생성
- [ ] 직접 질문 일일 제한과 테스트·운영 값 확인
- [ ] 개인화 완료 후 위치·날씨 선제 추천
- [ ] 위치 거부·날씨 실패 시 위치 없는 추천으로 정상 fallback
- [ ] AI 문구에 파트너 A·B, 실제 ID, 민감 추론이 노출되지 않음

- [ ] 녹음 음성을 게시 전에 검사

- [ ] 카드·답변·AI 결과 신고와 중복 제출 방지
- [ ] 신고 내용이 다른 사용자에게 노출되지 않음
- [ ] 상대방 차단 시 즉시 연결 해제·공유 데이터 숨김

- [ ] 계정 삭제가 모든 커플 공유 데이터와 Auth 계정을 제거
