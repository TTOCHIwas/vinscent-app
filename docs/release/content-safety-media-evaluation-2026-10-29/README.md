호출 흐름은 실제 bytes 디코딩 → OCR 또는 VAD/ASR → 텍스트 moderation → 조합 결과다.
이미지는 별도 시각 moderation도 먼저 수행한다. 네 불일치 모두 관측 추출문이 대본과 CER 0이고
텍스트 분류 자체에서 기대와 다른 판정이 확인됐다. 기대 대본을 대신 넣은 결과가 아니다.
강요 이미지의 최종 allow는 현재 조합에서 시각·텍스트가 모두 allow였다는 뜻이다.
금지 이미지의 개별 시각 판정은 저장하지 않아 이를 별도로 확정하지 않는다.

따라서 이번 사례의 차이를 OCR/ASR 문자 누락이나 HTTP 실패로 설명할 근거는 없다.
제품의 강요 차단·금지 맥락 허용 기준과 공급자 분류의 적합성이 부족하다는 관측이다.
공급자 내부 원인·단일 category score는 수집하지 않아 확정할 수 없다.
정책이나 라벨을 바꿔 결과를 맞추거나 추가 호출로 좋은 결과를 고르지 않았다.
