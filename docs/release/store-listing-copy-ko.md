# 단짠 스토어 등록 문구 초안

이 문서는 Google Play와 App Store Connect에 입력할 한국어 문구와 스크린샷,
심사 메모의 기준안이다. 실제 출시 후보에 없는 기능, 암호화 수준, 응답 시간,
AI 정확도를 약속하지 않는다.

## 2. Google Play

### 짧은 설명

> 둘만의 카드, 목소리, 일정과 질문을 함께 쌓는 커플 기록 앱

### 전체 설명

> 둘의 하루를 카드 한 장으로 남기고, 서로의 목소리와 답변을 함께 간직해
> 보세요.
>
> 단짠에서는 연결 코드를 통해 두 사람이 하나의 공간을 만듭니다. 사진을
> 찍거나 그림을 그리고 짧은 글을 더해 오늘의 카드를 올릴 수 있어요. 두
> 사람의 카드가 모이면 함께 답할 질문이 이어지고, 남긴 답변은 캘린더에서
> 다시 볼 수 있습니다.
>
> 둘만의 캐릭터를 직접 그리고, 캐릭터를 길게 눌러 짧은 목소리를 남겨
> 보세요. 마음에 드는 녹음은 그림을 더한 슬롯에 보관하고 홈 화면에 자유롭게
> 배치할 수 있습니다.
>
> 공유 캘린더에는 일정과 메모, 알림을 추가할 수 있습니다. 직접 그린 일정
> 그림과 카드가 날짜마다 쌓이고, 만난 날을 기준으로 한 기념일도 함께
> 확인할 수 있어요.
>
> 두 사람이 동의하면 답변을 바탕으로 기억을 하나씩 확인하고, 둘에게 맞는
> 질문과 한마디를 받을 수 있습니다. AI가 만든 내용은 앱 안에서 별도로
> 표시되며, 학습 동의와 기억 확인 상태는 언제든 확인할 수 있어요.
>
> 홈 화면 위젯에서는 캐릭터와 최근 카드를 빠르게 확인할 수 있습니다.
> 지원되는 기기에서는 위젯에서 짧은 녹음을 남기거나 재생할 수도 있어요.
>
> 계정과 공유 데이터는 설정에서 직접 삭제할 수 있습니다. 커플 연결을
> 해제한 뒤 보관 데이터를 즉시 지우거나, 계정을 삭제해 두 사람이 함께 만든
> 카드, 답변, 녹음, 캐릭터, 일정과 AI 데이터를 삭제할 수 있습니다.

## 4. 스크린샷 구성

스크린샷은 실제 출시 후보와 연결된 테스트 계정에서 만들고 개인정보와
실제 상대방 데이터는 넣지 않는다.

| 순서 | 화면 | 전달할 내용 |
|---:|---|---|
| 1 | 홈 | 두 사람의 카드, 직접 그린 캐릭터, 질문이 한 화면에 모이는 경험 |
| 2 | 카드 편집 | 사진, 그림, 텍스트와 짧은 글로 카드를 만드는 과정 |
| 3 | 질문과 답변 | 두 사람이 같은 질문에 답하고 기록을 확인하는 흐름 |
| 4 | 캘린더 | 카드, 일정 그림, 기념일과 날짜별 상세 기록 |
| 5 | 녹음 보관함 | 짧은 목소리를 슬롯에 저장하고 그림을 더하는 기능 |
| 6 | 우리 둘의 AI | 동의, 기억 확인, 직접 질문과 AI 생성 표시 |
| 7 | 홈 화면 위젯 | 캐릭터·카드 위젯과 지원 기기의 녹음 동작 |
| 8 | 설정 | 알림, 차단·신고, 커플 연결 해제와 계정 삭제 경로 |

휴대전화와 태블릿 이미지는 각 기기에서 직접 캡처한다. 휴대전화 이미지를
늘이거나 태블릿 프레임 안에 합성하지 않는다.

## 5. 심사 메모 기준안

심사 메모에는 비밀번호와 연결 코드를 이 문서나 저장소에 고정하지 않고,
제출 시점에 유효한 두 테스트 계정을 별도 입력한다.

1. 첫 번째 테스트 계정으로 로그인한다.
2. 두 번째 테스트 계정과 연결된 준비 상태인지 확인한다.
3. 홈에서 카드 상세 보기, 질문 답변, 캐릭터 녹음·재생을 확인한다.
4. 캘린더에서 카드와 공유 일정의 날짜별 상세를 확인한다.
5. AI 탭에서 두 사람의 동의 상태, 확인된 기억, 직접 질문 결과와 AI 생성
   표시를 확인한다.
6. 운영체제의 위젯 추가 화면에서 단짠 캐릭터와 카드 위젯을 추가한다.
7. 설정에서 콘텐츠 신고·사용자 차단, 커플 연결 해제, 계정 삭제 경로를
   확인한다.

AI 질문과 한마디는 서버의 비동기 작업으로 생성되어 네트워크 상태에 따라
수 분이 걸릴 수 있음을 심사 메모에 알린다. 위젯 녹음은 운영체제와 권한에
따라 동작이 달라질 수 있으므로 Android와 iOS의 실제 재현 절차를 각각
첨부한다.

## 6. 제출 전 확인

문구 길이와 단일 행 필드, App Store 키워드는 다음 종료형 검증 도구로
확인한다. 이 문서의 인용문 블록이 스토어 문구의 단일 원본이다.

```powershell
cd apps/mobile
..\..\.toolchains\flutter\bin\dart.bat run tool/verify_store_listing_copy.dart
```

- 앱 이름, 짧은 설명, 전체 설명, 부제, 프로모션 텍스트, 키워드의 제한 통과
- 실제 출시 후보와 설명의 기능 일치
- 결제하지 않아도 되는 기능을 유료 기능처럼 표현하지 않음
- AI 결과를 사람의 판단이나 관계 진단으로 표현하지 않음
- 개인정보처리방침, 이용약관, 안전 이용 약속, 외부 계정 삭제 URL 연결
- 스크린샷에 디버그 배너, overflow 경고, 실사용자 개인정보가 없음
- 심사용 두 계정과 커플 연결 상태가 심사 기간 동안 유지됨
