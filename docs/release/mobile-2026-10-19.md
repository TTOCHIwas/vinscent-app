# 2026-10-19 모바일 통합 배포

## 대상

- 사용자 승인: 현재까지 구현한 변경을 배포한다.
- Android: Google Play 내부 테스트.
- iOS: TestFlight.
- 앱 버전: `1.0.0`, 배포 빌드 번호: `2026101905`.
- 월간 회고 단일 화면·사진 더미·공통 헤더와 타이포, 미디어 로딩 및 캐시, Cupertino 입력창과 무채색 포커스, AI 안내·캐릭터 정렬, 답변 신고 버튼, 캘린더 경로 보호와 기념일 손그림 밑줄을 포함한다.
- 로컬 임시 캡처·진단 로그·환경 파일·작업용 스킬 설정은 배포 소스에 포함하지 않는다.

## 배포 경로

- 기존 `android-release.yml`과 `ios-release.yml`을 사용한다. main의 동일한 전체 SHA를 확인한 뒤 서명된 산출물을 업로드한다.
- 연결된 Mac mini는 현재 채팅의 프로젝트/실행 환경으로 등록되어 있지 않다. 현재 XcodeBuildMCP의 `list_sims`는 Windows에서 `xcrun ENOENT`를 반환했다. 이번 iOS 배포는 기존 GitHub `macos-26` runner를 사용한다.
- 이번 소스에는 새 DB migration이나 Edge Function 변경이 없다. 이전 운영 조회 migration은 기존 성공 배포 기록을 유지하며 이번에는 다시 실행하지 않는다.

## 검증

- 통합 배포 소스의 전체 Flutter 회귀 1,367개 통과·기존 제외 1개. 로그: `.codex-temp/release-20261019-full-test.log`.
- 저장소 릴리스 계약 검사 77개 통과.
- 형식 검사에서 발견한 `character_editor_screen.dart` 한 파일의 들여쓰기를 정리했다. 동작은 변경하지 않았다.
- 최종 스테이징 117개 파일에 대한 코드 리뷰에서 배포 차단 사항 없음. `git diff --cached --check` 및 tracked secret guard(1,546개 파일·1,433개 텍스트 파일) 통과. Android 전체 ABI AAB와 iOS 배포 서명·업로드는 각 릴리스 workflow에서 별도로 검증한다.
- 각 기능의 실제 기기 확인과 한계는 [공통 UI 검증 기록](ui-input-and-ai-alignment-2026-10-18.md), [미디어 로딩 기록](../media-loading-2026-10-18.md), [회고 기기 기록](monthly-retrospective-2026-10-16.md)에 있다.
